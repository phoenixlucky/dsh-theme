# WJ Dreamlight

WJ Dreamlight contains the complete six-theme wallpaper gallery: VIP Golden Radiance, Sea Salt, Bamboo Green, Coral Pink, Lavender, and Midnight Indigo. Open **Settings → General → Themes and wallpaper** to preview a wallpaper before applying its palette, and tune the sidebar and conversation background transparency independently from 0% to 100%. Values are saved in the current profile and restored on clients that load this Web plugin, including an explicit light or dark choice made in Appearance. At 0%, theme surfaces retain their original fills; wallpaper visibility at higher values depends on the host canvas. VIP Golden Radiance keeps the existing page layout and button styling, with warmer glass surfaces across the main canvas, plugin discovery, and automation pages, a subtle gold headline shimmer, and soft amber sidebar lighting. The headline shimmer and icon glow respect the system reduced-motion preference. Disabling the bundle removes the gallery, all six themes, and their assets.

The stylesheet source lives at `src/client/styles.css`; run `pnpm run sync:client-styles` after editing it to refresh the client bundle. The published package keeps the runtime font and its license files, without a second copy of the original font.

Enable **WJ Dreamlight** from **Settings → Plugins → More → Official**. The profile keeps the installed bundle across DSH application upgrades. Disable the bundle from the same page to return to the built-in theme selected by the theme service.
