# VIP Golden Radiance

This bundle contains the complete six-theme wallpaper gallery: VIP Golden Radiance, Sea Salt, Bamboo Green, Coral Pink, Lavender, and Midnight Indigo. Each card selects its palette and matching wallpaper. VIP Golden Radiance keeps the existing page layout and button styling, with warmer glass surfaces, a subtle gold headline shimmer, and soft amber sidebar lighting. The headline shimmer and icon glow respect the system reduced-motion preference. Disabling the bundle removes all six cards and their assets.

The stylesheet source lives at `src/client/styles.css`; run `pnpm run sync:client-styles` after editing it to refresh the client bundle. The published package keeps the runtime font and its license files, without a second copy of the original font.

Enable it from **Settings → Plugins → More → Official**. The profile keeps the installed bundle across DSH application upgrades. Disable the bundle from the same page to return to the built-in theme selected by the theme service.
