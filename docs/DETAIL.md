# VIP Golden Radiance

This bundle contains the complete six-theme wallpaper gallery: VIP Golden Radiance, Sea Salt, Bamboo Green, Coral Pink, Lavender, and Midnight Indigo. Each card selects its palette and matching wallpaper. The VIP theme also enables its display font, gold accents, sidebar treatment, glass surfaces, and light effects. Disabling the bundle removes all six cards and their assets.

Enable it from **Settings → Plugins → More → Official**. The profile keeps the installed bundle across DSH application upgrades. Disable the bundle from the same page to return to the built-in theme selected by the theme service.
