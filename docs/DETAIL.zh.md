# WJ 星耀主题

为 Web 配置档案带来六款主题壁纸与配色，一键切换不同视觉风格。选择主题后，界面配色与对应壁纸会同步切换。

## 六款主题，一键切换

包含 **VIP 金耀、海盐蓝、竹青、珊瑚粉、薰衣草紫、午夜靛蓝** 六款主题。

**VIP 金耀**以金色界面为主调，搭配显示字体、金色强调、侧栏样式、玻璃质感与光影效果，呈现更有层次的视觉体验。

## 启用与停用

前往 **设置 → 插件 → 更多 → 官方**，找到「WJ 星耀主题」并启用。配置档案会在 DSH 应用升级后保留已安装的插件。

从同一页面停用插件后，六款主题卡片及相关资源会一并移除，主题服务恢复为内置主题。
