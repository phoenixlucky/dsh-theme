# WJ 星耀主题

为 Web 配置档案带来八款主题壁纸与配色。图库现在是设置里的独立页面：前往 **设置 → 主题与壁纸**，先预览主题，再应用切换；还可分别设置侧边栏与对话区的背景透明度（0–100%）。设置保存在当前配置档案，并在加载此 Web 插件的端恢复；在外观中明确选择的浅色或深色也会一并保存。透明度为 0 时保留原主题表面；调高后壁纸能否显示取决于宿主画布是否透明。

## 八款主题，一键切换

包含 **VIP 金耀、端午龙舟、清明踏青、七夕鹊桥、元宵灯会、中秋月境、万圣夜、圣诞雪境** 八款主题。新增的五款中国节日壁纸沿用 VIP 壁纸中的蓝紫长发女孩形象，每款均保留鲸鳍耳饰、鲸尾配件和蓝色鲸鱼玩偶；万圣夜与圣诞雪境保持原样。

**VIP 金耀**保留原有页面布局与按钮样式，通过更暖的玻璃表面、金色标题微光和柔和的侧栏暖光增强主题辨识度。标题微光和图标呼吸光会遵循系统的减少动态效果设置。

其余七款主题共用同一套通用效果层：由各自的主题色和明暗基底派生玻璃面板、强调色边框、悬停/选中态、滚动条着色，以及壁纸上方的主色氛围层与底部压暗，因此壁纸不再是「一张图 + 一个主色」的平涂效果。

## 自定义主题

在图库底部点「添加自定义主题」，填写名称、图片地址、主题色和明暗外观即可。图片支持 `https://`、`data:image/` 和应用内 `/` 开头的地址；主题色会驱动该主题的全部强调效果。自定义主题与内置主题同屏显示并带「自定义」标记，可在预览里编辑或删除，配置保存在 `dsh-theme` 的 `customThemes` 字段中。

代码层面新增主题只需一条声明，不需要写 CSS：

```js
createWallpaperTheme({
  id: "official-my-theme",
  colorScheme: "light",
  accent: "#4d91b7",
  surface: "#f6fbff",
  wallpaper: myWallpaperAsset,
  labels: { zh: "我的主题", en: "My theme" }
});
```

效果输入只有 `--dsh-theme-accent` 与 `--dsh-theme-surface`，其余派生值都以 `--dsh-theme-*` 命名空间暴露，主题可按需覆盖；动效、悬停、玻璃、边框、氛围层各自独立成 token，并遵循 `prefers-reduced-motion`。

样式源码位于 `src/client/styles.css`，修改后运行 `pnpm run sync:client-styles` 更新客户端 bundle。发布包保留运行时字体和许可文件，不再重复包含原始字体副本。

## 启用与停用

前往 **设置 → 插件 → 更多 → 官方**，找到「WJ 星耀主题」并启用。配置档案会在 DSH 应用升级后保留已安装的插件。

从同一页面停用插件后，八款主题卡片及相关资源会一并移除，主题服务恢复为内置主题。
