# WJ 星耀主题

为 Web 配置档案带来八款主题壁纸与配色。图库现在是设置里的独立页面：前往 **设置 → 主题与壁纸**，先预览主题，再应用切换；还可分别设置侧边栏与对话区的背景透明度（0–100%）。设置保存在当前配置档案，并在加载此 Web 插件的端恢复；在外观中明确选择的浅色或深色也会一并保存。内置配色命名空间只保存浅色、深色和系统三种值，因此壁纸主题 id 由本插件保存：宿主因设置更新而重新采用内置配色时，插件会立即恢复已保存的主题；在外观中选择浅色、深色或系统则会替换壁纸。透明度为 0 时保留原主题表面；调高后壁纸能否显示取决于宿主画布是否透明。

## 八款主题，一键切换

包含 **金耀财神、端午龙舟、清明踏青、七夕鹊桥、元宵灯会、中秋月境、万圣夜、圣诞雪境** 八款主题。新增的五款中国节日壁纸沿用金耀财神壁纸中的蓝紫长发女孩形象，每款均保留鲸鳍耳饰、鲸尾配件和蓝色鲸鱼玩偶；万圣夜与圣诞雪境保持原样。

**金耀财神**保留原有页面布局与按钮样式，通过更暖的玻璃表面、金色标题微光和柔和的侧栏暖光增强主题辨识度。标题微光和图标呼吸光会遵循系统的减少动态效果设置。

其余七款主题共用同一套通用效果层：由各自的主题色和明暗基底派生玻璃面板、强调色边框、悬停/选中态、滚动条着色，以及壁纸上方的主色氛围层与底部压暗，因此壁纸不再是「一张图 + 一个主色」的平涂效果。

## 本地上传（只存一张）

图库底部有独立的「本地上传」区，点「上传本地图片」填写名称、图片、主题色和明暗外观即可；已有本地上传时按钮变成「编辑本地上传」，改的就是同一张。图片有两种来源：上传本机文件（或拖进虚线框），或在地址框填写 `https://`、`data:image/` 或应用内 `/` 开头的地址；主题色会驱动该主题的全部强调效果。

内置的八款壁纸主题不占配置空间：选中它们只记录一个主题 id，不含任何图片数据。切换内置主题只是改写所选 id，**不会清除已上传的那张**——切回自选壁纸可以继续用；只有预览里的「删除」或编辑器里的「移除本地图片」才会真正清掉数据。只有这张自选壁纸会把图片转成 base64 存进 `dsh-theme` 的 `customThemes`，而该字段最多一条：旧版本留下的多余条目读取时被忽略（优先保留当前正在使用的那张，否则取第一条），下次保存会把整个数组收拢成一条，槽位 id 保持不变，因此换图不会让已应用的主题掉回内置配色。这张壁纸与内置主题同屏显示并带「本地」标记，可在预览里编辑或删除。

### 本地上传：浏览器内转 WebP 再以 base64 保存

上传的图片不会离开浏览器：客户端用浏览器的图片解码管线读出像素（按 EXIF 方向摆正），画到 canvas 上重新编码为 WebP，再用 `FileReader` 读成 `data:image/webp;base64,…` 写进主题的 `wallpaper` 字段。编码器按最长边 2560 像素、质量 0.82 起步，若生成的 data URL 超过约 90 万字符，就依次降到 2200/2200/1920/1600/1280 像素与更低质量重试，最差情况下接受不超过 190 万字符的结果（此时编辑器提示画质可能下降），仍超出则报错要求换小图。原图上限 24 MB；WebP 保留透明通道；GIF 取第一帧。

这条链路只依赖浏览器自身能力，因此没有网络请求、不会把文件复制到其他目录，也不需要宿主提供文件接口。宿主侧 `wallpaper` 字段的 schema 上限相应放宽到 200 万字符，读取时超过上限的条目会被丢弃而不是让整份配置失效。若浏览器没有 WebP 编码器（`canvas.toBlob` 静默返回 PNG），编辑器会明确报错而不是偷偷存成别的格式。

编辑一个已保存本地上传的主题时，地址框会换成缩略图和「本地图片（WebP）· 尺寸 · 大小」摘要，避免把百万字符的 base64 塞进输入框；点「移除本地图片」可清空后改填地址，重新上传则覆盖原图。保存流程会等待配置档案确认写入后再关闭编辑框，因此新主题会立即出现在图库中。

## 毛玻璃与透明度

「背景与效果」区有三个 0–100% 的滑杆：侧边栏背景透明度、对话区背景透明度，以及毛玻璃强度。前两者只调整面板填充的透明度（数值就是该区域透出的壁纸比例：宿主把每个填充画两遍——侧栏列加其根节点、中列加对话根节点——所以客户端写的是滑杆值的平方根；Windows 桌面端还会摘掉宿主用侧边栏填充画的窗口底，那层原本垫在对话列下面），毛玻璃则是**全局一层**：客户端插入一个插件自有的固定层（`.dsh-theme-glass-layer`）承载当前壁纸，开启时给这层加上 `blur(0.26px × 强度)` 与 `saturate()`，再叠一层很淡的霜化渐变；关闭时该层不显示，壁纸保持锐利。

因为模糊发生在壁纸层而不是宿主面板上，它对所有壁纸主题都生效——八款内置主题和那张本地上传一样可调，而且不会往配置里写任何图片数据（只存一个 0–100 的强度值）。强度 ≥60 时记为强档。开启后图库卡片与对话框也会用 `backdrop-filter` 呈现磨砂质感。这一层由 `ctx.effect` 创建并在插件卸载时移除，不改写宿主 DOM。

## 编辑框排版

自定义壁纸的编辑框按「标题 + 说明 → 名称 → 壁纸投放区 → 主题色 / 外观 → 分隔线 + 动作」排布：壁纸投放区在有图时显示 16:9 预览与「尺寸 · 大小」胶囊标签，无图时是虚线投放框加一个主按钮；外观改成浅色/深色两段式切换并带 `aria-pressed`，主题色旁显示十六进制值。投放区支持拖放，转换或保存期间按钮禁用并显示进度文案。

代码层面新增主题只需一条声明，不需要写 CSS：

```js
createWallpaperTheme({
  id: "official-my-theme",
  colorScheme: "light",
  accent: "#4d91b7",
  surface: "#f6fbff",
  wallpaper: myWallpaperAsset,
  labels: { zh: "我的主题", en: "My theme" }
});
```

效果输入只有 `--dsh-theme-accent` 与 `--dsh-theme-surface`，其余派生值都以 `--dsh-theme-*` 命名空间暴露，主题可按需覆盖；动效、悬停、玻璃、边框、氛围层各自独立成 token，并遵循 `prefers-reduced-motion`。

样式源码位于 `src/client/styles.css`，修改后运行 `pnpm run sync:client-styles` 更新客户端 bundle。发布包保留运行时字体和许可文件，不再重复包含原始字体副本。宿主插件资源路由只发图片（`.svg`、`.png`、`.webp`、`.jpg`、`.jpeg`），所以插件的宿主侧自己注册 `/theme-font` 路由，以不可变缓存流式发出 `.woff2`；客户端探测到该路由后才启用显示字体。宿主侧未挂载该路由时保留宿主文本字体。

## 启用与停用

前往 **设置 → 插件 → 更多 → 官方**，找到「WJ 星耀主题」并启用。配置档案会在 DSH 应用升级后保留已安装的插件。

从同一页面停用插件后，八款主题卡片及相关资源会一并移除，主题服务恢复为内置主题。
